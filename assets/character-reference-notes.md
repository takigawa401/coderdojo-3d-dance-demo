# 水色版の元絵と3D制作メモ

採用画像は `character-reference-v2.png`。1024 × 1536ピクセルのPNG。正面からの全身画で、顔、髪、服、靴を一枚で確認できる。キャラクターは14歳、身長140cmの設定。黒のショートボブ、大きな目と明るい笑顔、白い腕まくりシャツ、グレーのプリーツスカート、水色の腰巻きカーディガン、水色レースのシュシュ、白のルーズソックス、ローファーが目印。

| 元絵の特徴 | 3D制作時の扱い |
| --- | --- |
| 右手のピンクのスマホと曲げた肘 | 元絵には残す。ダンス用の本体は手ぶらとし、体の4方向画像は同じTポーズで作る。スマホを出す場合は、後から右手の骨に付けられる別の小物にする。 |
| カーディガンの結び目・垂れた袖とプリーツスカート | 前後・左右で色、丈、結び位置、裾の重なりを揃える。3D候補と再生中の両方で袖や裾が脚や手にめり込まないか確認する。必要な箇所だけ分離や揺れを調整する。 |
| 水色の背景と水色のカーディガン・シュシュ | 元絵の輪郭は見えている。Tripo入力用の部位画像では、背景を外し、小物と服の輪郭・配色を見比べる。シュシュは左手首。 |
| 開いた口の笑顔と黒いボブ | 頭の4方向画像は口を閉じた穏やかな表情を基本にし、目の大きさ、輪郭、髪型を保つ。笑顔は時間があれば表情として追加する。 |
| 140cmの設定 | 画像だけで実寸は決まらない。位置・サイズ調整で足裏から頭頂までを目標1.40 mに合わせ、書き出したVRMで確認する。 |

元絵にない背面は、ボブの長さ、シャツ、プリーツ、腰のカーディガンが前面と自然につながるよう補う。頭と体の各4方向を先に見比べ、配色や左右が揃ってからTripoへ渡す。 [Charakuru公式チュートリアル](https://github.com/nanocle/Charakuru/blob/main/docs/tutorial.ja.md)

## 水色版への変更内容

初稿は `character-reference-prompt.txt` を使用。修正版は初稿を参照し、腰に結んだカーディガンの結び目・袖・裾を左手首のシュシュに合わせた水色に変更。スマホケースはピンク。今後の元絵には修正版のPNGを使う。
